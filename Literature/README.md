# Literature manifest

Third-party papers are cited rather than redistributed. The local PDF copies
were removed from the current Git index on 2026-08-22 because the repository
did not contain evidence that their publishers/authors granted redistribution
rights. `.gitignore` keeps a researcher's private local copies out of commits.

Use [`models/references.md`](../models/references.md) as the maintained IEEE
bibliography. Retrieve papers through the publisher, DOI, institutional library,
or an author-provided open-access copy and comply with its terms.
