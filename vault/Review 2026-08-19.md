# Review — 2026-08-19

Full read of every source file, model artifact, results CSV and deploy script,
plus a run of `tests/smoke_test.py` (23 pass / 1 fail — see [[F16 - Moderate issues roundup]]).

## Verdict

The engineering is strong: one shared feature extractor used by trainer, daemon
and C exporter (no train/serve code skew), a real ONNX→C parity check, a 24-check
smoke suite, honest caveats in the README, and a working IPS + dashboard +
systemd path.

The problems cluster in two places:

1. **The live daemon** has correctness and scaling bugs that only manifest on
   real hardware under real load — [[F04 - Live mode reclassifies the entire flow table]],
   [[F05 - Data race between sniffer thread and flush loop]].
2. **The SFAF cross-dataset study's headline conclusion is confounded** by broken
   feature mappings and a degenerate metric — [[F01 - SFAF feature mappings are semantically wrong]],
   [[F02 - Cross-domain F1 includes degenerate classifiers]]. This matters most,
   because it is the thesis contribution.

## The two findings that change the conclusions

The README states the honest finding as *"in-domain F1 0.98 vs cross-domain 0.45
— a 0.53 gap; this is the overfitting problem, quantified."*

That claim is not safe as measured, for two independent reasons:

- **Misalignment.** Port numbers are mapped into packet-length features, byte
  counts into packet-rate features, and flow duration is in microseconds for
  some datasets and seconds for others with no conversion. A large part of the
  measured "gap" is self-inflicted. → [[F01 - SFAF feature mappings are semantically wrong]]
- **Metric degeneracy.** Test sets are ~50/50 balanced, so *always predict
  attack* scores F1 = 0.667. 21% of off-diagonal cells sit in [0.63, 0.70], and
  the row the findings doc calls "generalizes best" (`iotid20`) is almost
  exactly 0.667 across the board. That is not transfer; that is a degenerate
  classifier. → [[F02 - Cross-domain F1 includes degenerate classifiers]]

Neither invalidates the project — they make the result *fixable*, and the
corrected result is a stronger, more publishable claim.
